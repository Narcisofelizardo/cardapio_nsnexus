MenuX Prime - Cardápio Digital Premium

VERSÃO CORRIGIDA

Agora o sistema funciona abrindo o index.html direto no navegador, sem precisar de servidor local.

Arquivos principais:
- index.html
- styles.css
- script.js
- data/menu.js
- data/menu.json
- assets/*

Como usar:
1. Extraia o ZIP.
2. Abra o arquivo index.html.
3. Para editar produtos, nome da empresa, WhatsApp e preços, altere o arquivo:
   data/menu.js

Também mantive o data/menu.json para uso futuro em servidor/hospedagem.

Importante:
Não apague a pasta data nem a pasta assets.
